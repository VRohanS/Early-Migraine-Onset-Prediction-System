# Early-Migraine-Onset-Prediction-System
Early Migraine Onset Prediction System using Machine Learning with Flask, Random Forest, and symptom-based analysis. Predicts early migraine risk using Random Forest and symptoms like photophobia, phonophobia, and typing patterns.
Useful for early diagnosis of migraine and taking necessary precautions.
Runs in the background to detect the necessary factors. Web app displays the history of predictions.
